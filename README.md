# لندینگ‌پیج رسمی فروشگاه اینترنتی مبیت (Mobit Landing Page)

این پروژه پیاده‌سازی کامل و مدرن لندینگ‌پیج فروشگاه اینترنتی **مبیت ([mobit.ir](https://www.mobit.ir/))** بر پایه فریم‌ورک پایتون **Django** و فرانت‌اند استاندارد **HTML5, Tailwind CSS, JavaScript (Vanilla ES6)** و معماری واکنش‌گرا (Responsive RTL) است.

---

## 🎨 هویت بصری و ویژگی‌های اختصاصی پیاده‌سازی شده از مبیت

1. **هویت و پالت رنگی رسمی مبیت:**
   - رنگ سرمه‌ای / آبی رویال مبیت (`#034694`)
   - رنگ قرمز / مرجانی شکار تخفیف (`#ef4056`)
   - لوگوی وکتور رسمی مبیت (`logo-mobit.svg`)
2. **شکار تخفیف مبیت (Flash Sale Deals):**
   - اسلایدر با کانتینر گرادینت اختصاصی و شعله آتش
   - تایمر شمارش معکوس زنده و ثانیه‌شمار دقیق با ارقام فارسی
   - کارت‌های کالا با درصد تخفیف، قیمت خط‌خورده و قیمت نهایی
3. **دسته‌بندی‌های محبوب (Quick Categories):**
   - ۹ دسته‌بندی گرد با آیکون‌های رسمی WebP مبیت، افکت هاور و نمایش نام فارسی و انگلیسی
4. **اسلایدر بزرگ بالای صفحه (Hero Slider):**
   - بنرهای عریض دسکتاپ و ریسپانسیو مبیت
   - کنترل خودکار، توقف با نگه داشتن ماوس، دکمه‌های قبلی/بعدی و نقاط نشانگر
5. **ویترین تب‌های محصولات منتخب:**
   - تب‌های پرفروش‌ترین‌ها، پربازدیدترین‌ها، جدیدترین‌ها، گیمینگ و کنسول، لوازم جانبی اصلی
   - جابجایی فوق‌سریع بدون نیاز به رفرش صفحه
6. **پیش‌نمایش سریع کالا (Quick View Modal):**
   - مشاهده مشخصات فنی، رنگ‌بندی، گارانتی طلایی، امتیاز و دیدگاه‌ها در مودال اختصاصی
7. **سبد خرید تعاملی (Interactive Cart Drawer):**
   - ذخیره در `localStorage`، شمارشگر زنده در هدر، قابلیت کم/زیاد کردن تعداد و حذف کالا، محاسبه فاکتور به تومان
8. **جستجوی آنی و هوشمند (Live Search Preview):**
   - جستجو در نام فارسی، عنوان انگلیسی، برند و مشخصات با میانبر کیبورد `Ctrl + K`
9. **انتخاب شهر مقصد تحویل (City Selector Modal):**
   - انتخاب کلان‌شهرها و شهرستان‌ها جهت محاسبه رویه‌های ارسال مبیت اکسپرس
10. **خبرنامه تخفیف‌ها با AJAX:**
    - ثبت شماره یا ایمیل با بازخورد آنی نوتیفیکیشن Toast فارسی
11. **فوتر جامع و حقوقی مبیت:**
    - آدرس دفتر مرکزی و انبار در کرمان (میدان قرنی، ساختمان پدر)، تلفن پشتیبانی (۰۳۴-۹۱۰۰۲۴۲۵)، نمادهای اعتماد و لینک‌های راهنمای مشتریان

---

## 🚀 نحوه اجرای سریع پروژه

### ۱. اجرای سرور توسعه جنگو
```bash
# در پوشه پروژه:
source .venv/bin/activate
python manage.py runserver
```

سپس در مرورگر خود باز کنید:
👉 **http://127.0.0.1:8000/**

---

## 🛠️ بازنشانی یا بارگذاری داده‌های دمو (Seed Data)

داده‌های رسمی و واقعی استخراج‌شده از مبیت در دیتابیس بارگذاری شده‌اند. در صورت نیاز به بازنشانی:

```bash
python manage.py seed_data
```

---

## 👤 پنل مدیریت (Admin)

جهت ورود به پنل مدیریت برای کنترل دسته‌بندی‌ها، کالاها، بنرها و اعضای خبرنامه:

```bash
python manage.py createsuperuser
```
سپس به آدرس **http://127.0.0.1:8000/admin/** مراجعه کنید.

---

## 🧪 اجرای تست‌های خودکار

```bash
python manage.py test
```
تمام تست‌های صفحه اصلی، جستجوی زنده، مودال مشخصات و خبرنامه به طور کامل پاس می‌شوند.
